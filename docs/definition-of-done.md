# Definition of done

The nine items are policy: see
[community files, documentation and definition of done](https://github.com/simpsonm09-projects/.github/blob/main/standards/owner.md#community-files-documentation-and-definition-of-done).

The pull request template asks for the same proof, so a reviewer does not need this page
to check a change:

- `.github/pull_request_template.md` asks what changed, how it was verified and what
  context a reviewer needs.
- `docs/exceptions.md` records a rule the repository cannot meet, with the rule id, the
  reason and a revisit date.

A change is not done when a required check is red, when the only proof is that it
compiles, or when a gap is excepted without a recorded reason.
